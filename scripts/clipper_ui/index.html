    YouTube setup

    1. In Google Cloud Console, create a project and turn on YouTube Data API v3.
    2. Set up the OAuth consent screen as External, add your Google account as a test user, then publish it to production so the sign-in doesn't expire after 7 days. It can stay unverified.
    3. Under Credentials, create an OAuth client ID of type Desktop app and download the JSON.
    4. Save it as workspace/data/youtube_client.json in this app's folder, then reload this page.
