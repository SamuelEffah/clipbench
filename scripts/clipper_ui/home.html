Set up YouTube

  1. In Google Cloud Console, enable YouTube Data API v3 and configure the OAuth consent screen for your account.
  2. Create a Desktop app OAuth client and download its JSON file.
  3. Save it as youtube_client.json in your app’s data/ folder (or your configured CLIPBENCH_DATA folder).
