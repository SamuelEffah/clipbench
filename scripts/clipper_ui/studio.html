Set up YouTube

  1. Enable YouTube Data API v3 and configure the OAuth consent screen in Google Cloud Console.
  2. Create a Desktop app OAuth client and download its JSON file.
  3. Save it as youtube_client.json in your app’s workspace/data/ folder (or configured CLIPBENCH_DATA folder).
